# РБО × Авито: помощник по диким животным — кликабельный прототип

Мобильный прототип (до ~800 px) для проверки UX: лендинг с новым первым экраном,
сценарный чат-помощник и экраны результата. Картинок нет — только заглушки.
Ответы помощника прописаны заранее (Wizard of Oz), модели и бэкенда нет.

## Как открыть

Откройте `index.html` в браузере — сборка не нужна. Или локальный сервер:

    python3 -m http.server 8000

Прямые ссылки на экраны результата: `index.html?demo=1` … `?demo=6`
(порядок как в меню прототипа — иконка «?» в шапке чата).

## Что внутри

| Экран | Что проверяем |
| --- | --- |
| Лендинг | Страница перестроена вокруг помощи. Первый экран: поле «Опишите, что произошло», кнопка «Получить помощь» и быстрый выбор животного (сразу запускает сценарий); «Поддержать РБО» — второстепенно, в шапке. Дальше: три правила и 112, контакты специалистов с кнопками «Позвонить / Написать» и подбором центра по региону. Блоки о РБО и проектах — ниже, под разделителем «О проекте» |
| Помощник | Свободный ввод «Опишите, что произошло» + быстрые ответы кнопками. Нейтральный вид, без стиля Ави |
| Результат | Исход, 1–3 шага, «чего не делать», карточка контакта, запасной контакт, вопрос «Получилось связаться?» |

Сценарии:

1. **Слёток** → «скорее всего, помощь не нужна»; контакт скрыт за кнопкой «Всё равно хочу посоветоваться».
2. **Раненая птица** → «свяжитесь со специалистом»; мессенджер приоритетно, «что отправить».
3. **Лосёнок у дороги** → предупреждение до любых вопросов; «наблюдайте» либо, если животное на проезжей части, «опасно, отойдите» + 112.
4. **Нет ответа / нет покрытия** → «Не дозвонился» на экране результата (мессенджер + запасной центр; повторно — общая линия РБО); регион «Другой регион» — «пока нет партнёров» + дистанционная консультация.

## Решения из исследования, заложенные в прототип

- **Правила сразу.** Блок «чего не делать» появляется в чате после первого же сообщения, до уточняющих вопросов.
- **Безопасность раньше диалога.** Для крупных и хищных животных предупреждение показывается до любых вопросов.
- **«Не вмешиваться» — полноценный исход**, а не отказ: у него те же шаги и объяснение «почему».
- **Сначала регион, потом детали.** Организация подбирается по региону и группе животных.
- **Не больше 3–4 вопросов** после первого сообщения.
- **Мессенджер как основной или запасной канал**, пометка «могут ответить не сразу», всегда есть запасной контакт.
- **Пожертвование — только после сценария помощи** (после ответа «Да, получилось связаться»).
- Помощник не ставит диагноз, не советует лечение, не обещает выезд.

## Что нужно сверить с РБО

- Все формулировки шагов и запретов в `js/data.js` — черновик.
- Контакты: телефоны РБО взяты с текущего лендинга; мессенджеры, часы работы, запасные и
  региональные центры — заглушки (в интерфейсе помечены «заглушка»).
- Кнопки звонка и мессенджера в прототипе ничего не открывают — показывают подсказку.
