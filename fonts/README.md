Шрифт прототипа — CoFo Avito Text (Regular, Medium, Bold).

Если шрифт установлен в системе, он подхватится сам. Чтобы он работал на телефоне
или на GitHub Pages, положите сюда файлы `CoFoAvitoText-Regular.otf`,
`CoFoAvitoText-Medium.otf`, `CoFoAvitoText-Bold.otf`.

Файлы шрифта в репозиторий не добавлены (см. `.gitignore`): шрифт фирменный,
решение о публикации — за командой.
